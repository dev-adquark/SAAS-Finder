# SaaS Finder
SEO-first SaaS reviews, alternatives and comparison foundation built with Next.js, TypeScript and Tailwind CSS.

## MVP
Product catalog, structured review pages, category hubs, alternatives, responsive UI, methodology and affiliate disclosure.

## Roadmap
Prisma/Neon database, admin workflow, affiliate tracking, comparison engine, sponsor slots, analytics, sitemap/robots, JSON-LD, freshness/changelog, automated QA and CI.
